## 命令

- `#bz db 蓝宝石`：默认展示全部可用品质。
- `#bz db 限速器`：技能图片，通用技能明确显示“适用英雄：全部英雄（通用）”。
- `#bz db 生命循环`：显示“适用英雄：瓦内莎、马克、卡诺克”。名称来自官方中文，英雄范围来自 GameData 的 Heroes 字段。
- `#bz db 船锚 -e` / `--enchants`：基础详情与附魔分页图片。船锚有 13 种附魔，通常生成两页。
- `#bz db 蓝宝石 --品质 黄金`：指定品质。
- `#bz db 蓝宝石 --品质 黄金 --附魔 寒冰`：指定品质和一种附魔。
- 支持 `--quality`、`--enchant` 以及品质、附魔的英文枚举；指定一种附魔与 `-e` 总览互斥。

## 实现

### 查询不到与备选（2026-10-26 已发布）

- 先精确查询本地名称；未命中再搜索本地相近名称，本地无候选时再查询远程来源。
- 本地唯一候选沿用直接展示详情；多个候选合并去重并按名称相关程度排序，总共最多 10 个。
- 每条明确标注“物品”“技能”“野怪”，野怪形态附带日期和等级；商店、遭遇事件接入查询时复用同一类型展示规则。
- 指定 `#bz db 技能 <名称>` 或 `物品`、`野怪` 后，只查询对应类型，过滤发生在截取数量之前。
- 远程卡牌搜索结果也标注类型、去重并限制最多 10 个；远程接口返回的首个模糊命中不再直接作为精确结果展示。
- 完全无候选时提示检查名称或换关键词；数据读取或远程接口异常保留对应失败提示。
- 验证：107 项本地测试通过；发布前及发布后均使用服务器 GameData 验证 `frost` 混合类型候选、指定类型、生命循环、船锚 `-e`、指定品质附魔与虚空骑士；远程兜底及 handle 使用受控响应和模拟事件，未向 QQ 发送测试消息。
- 本次仅更新服务器原版 `bazaar_plugin.py` 的查询方法及候选辅助函数、`gamedata_client.py` 的名称类型过滤。商店与遭遇事件样例不在本次发布范围。服务加载、NapCat 连接及文件哈希均通过核对。
