# 单物品阵容分析查询

2026-11-10 北京时间 10:25 发布。用户验收本地图片预览并明确授权上线。

- `#bz 阵容 原子钟` / `#bz comp Atomic Clock`：单物品阵容分析，支持官方中文、英文和现有物品别名。名称歧义时列出候选；技能不能作为查询物品。
- 可选参数：`--hero 杜利`、`--days 7`（1–365）、`--legendary`。默认当前版本、全部英雄和全部段位。
- 复用网站 `/api/comp/card` 分析缓存，使用 `sort=appearance`，按出场局数降序展示前三组至少 30 局的核心组合。没有主推荐时展示至多两组 10–29 局的小样本探索。
- 正式图片移除预览标记，突出出场局数与 10 胜率，中文标签紧跟数值；不展示组合出场率百分比。每组包含核心物品、前三个补充物品和技能。
- 搭配频率为该组合 10 胜局中的共现比例。保留不含 0 胜局的统计说明。图片内二维码带上当前筛选条件与出场排序；正常回复只发送图片，不再附带“完整分析”和网址文字。
- 机器人最多同时处理两个阵容查询，并遵守网站的一秒请求间隔。繁忙、预热、超时均返回可读提示。图片渲染、上传或发送被拒绝时返回文字统计，不附网址。
- 图片输出目录 `data/charts/comp/`；使用服务器现有卡图、中文字体和 qrcode 依赖，避免重复叠加网站水印。
- 更新普通用户帮助和机器人查询统计分类。
