# 商店与遭遇事件图片查询

2026-10-26 接入正式 `#bz db` 命令及群聊、私聊图片上传，修复此前只有验收预览、实际查询仍返回通用文字的问题。

## 命令

- `#bz db 米透`、`#bz db 杰杰`、`#bz db 旅行代理人`：自动识别商店。
- `#bz db 商店 米透`、`#bz db 商人 Mittel`：限定商店类型。
- `#bz db 事件 药房`、`#bz db 遭遇 药房`：限定遭遇事件；也支持 `merchant`、`event` 英文前缀。
- 同名跨类型先提示选择。例如“药房”同时有物品和事件，需指定 `物品` 或 `事件`。
- 同名遭遇优先正常出现版本；存在多个正常版本时，提示英雄范围和 `--形态 UUID` 指令进行选择。
- 模糊候选继续合并去重、最多 10 个，并标注物品、技能、野怪、商店、遭遇事件。

## 展示

商店展示插图、官方中文名称与简介、出现日期、英雄范围、可选数量、出售范围、购买及刷新规则。零次刷新与空值分别处理，费用递增和上限保留。不展示随机商品池举例，也不添加展开商品池入口。固定保证出售的商品展示真实卡图、品质边框、售价、效果，保持小中大物品原比例。

事件展示插图、日期、英雄、选择规则、选项的官方说明、费用及目标范围，保留条件分支。药房的三次付费强化以效果对照表展示；已知固定奖励展示物品或技能图片。大量随机奖励或重复转换条件归纳为生成规则与作用范围，避免把可能结果当成保证奖励。长内容分页，每页不超过 2400 像素。

日期记录区分官方公告、百科记录和实测覆盖，图片注明来源；未知日期或费用明确标注。官方词条中缺少中文的文字保留原文，不编造翻译。动态数值不能静态确定时标注动态。

## 数据与渲染

- `encounter_data.py` 读取官方 GameData、官方中文，并连接 EventEncounter、EncounterStep、PedestalEncounter、物品与技能记录。
- `encounter_sources.json` 按实体 ID、当前 ArtKey 对应插图，附有日期及出处。只有相同 ArtKey 才共享插图；透明头像退回完整场景图。
- `tools/fetch_encounter_sources.py` 从公开搜索页面建立插图映射，并从官方 Steam 公告提取明确日期。查询运行时使用本地快照，不依赖远程搜索接口。
- `encounter_image.py` 生成缓存分页图，复用既有字体、边框与原比例图片加载器。
- 命令中传递实际消息事件，完成 base64 图片上传；渲染或上传失败退回完整文字规则。
