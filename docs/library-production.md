# 图鉴构筑上线与使用统计

2026-10-27，用户明确验收通过并授权上线，同时要求后台查看使用率。

## 入口

- 正式页面：https://bazaarqiubot.com/library/ 。主站八个页面导航增加「图鉴构筑」。
- 后台：https://bazaarqiubot.com/admin/stats#features →「图鉴构筑 · 使用情况」，使用现有后台认证。
- 支持统一周期选择、操作次数／独立访客、每日明细和导出耗时／结果。
- staging 保持独立；不向生产统计上报。阵容路线入口保持下线。

## 口径

匿名浏览器标识单向哈希后去重，跨设备不合并；北京时间自然日统计，原始交互保留 90 天。

- 全站访客使用占比：图鉴访客／全站已埋点访客。全站范围沿用来源统计中有访问记录的访客，并合入有图鉴交互但页面上报缺失的访客。
- 构筑使用率：发生卡牌编辑、保存或新建操作的访客／图鉴访客。
- 导出使用率：成功生成并触发图片下载的访客／图鉴访客；不代表用户最终在磁盘保留文件。
- 图鉴访客：周期内有任何有效图鉴操作记录的匿名访客。无分母显示「—」。
- 搜索在停止输入 700ms 后记录；筛选按用户点击记录。初始化列表、图片加载和恢复当前构筑不计主动操作。
- 保存成功才记录保存事件，重复草稿不计成功保存。导出分别记录开始、成功、失败。
- 相同事件编号重试去重，同一页面会话的访问只记一次；每访客每分钟最多 240 条交互。
- 不上传搜索原文、草稿名称、完整构筑或原始异常内容。浏览器离线／拦截仍可能漏记。数据从本次上线开始，历史使用不能补录。

## 部署

- 独立 Gunicorn 服务 `qiubot-library`，127.0.0.1:1035；1 个 worker、8 线程，MemoryHigh=384MiB、MemoryMax=512MiB、CPUQuota=50%。Gunicorn 26.2.0 安装于既有 Python venv。
- 当前代码：`/opt/qiubot-library/current` → `/opt/qiubot-library/releases/20261026T162118Z`。
- 独立写入目录：`/var/lib/qiubot-library`。从已验收 staging 复制只读游戏数据与已缓存的原比例卡图，独立保存后续缓存。
- Caddy 仅新增 `/library` 重定向和 `/library/*` 代理。数据与资源使用 `/library/` 前缀。
- 埋点由现有主站处理：POST `/api/track/library`；后台 GET `/api/stats/library?days=7`。统计存于既有 `stats.db` 的 `library_event`／`library_meta`；来源和页面访问沿用已有接口。
- 主站源码来自部署前线上快照，只应用本次导入／注册、后台面板、来源路径与导航补丁，未发布工作区其他改动。仅重启 `web_runs`，未重启 QQ Bot。
- 备份：`/opt/qiubot-deploy-backups/library-20261026T162118Z`，包含原源码、Caddy、清单和回滚脚本。
- 本地发布及校验证据：`.tmp/library-production/`。
