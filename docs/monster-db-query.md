# `#bz db` 野怪查询

2026-10-26 发布。用户验收虚空骑士原比例卡图示例并明确授权上线后，部署到现有 QQ 机器人。

## 使用

- `#bz db 虚空骑士` / `#bz db Void Knight`
- `#bz db 野怪 <名字>`：指定野怪类型，避免与物品或技能重名。
- 部分名称返回候选；同名不同遭遇保留独立形态，回复给出可复制的 `--形态 <遭遇ID>` 命令。

图片包含官方中文名、野怪主图、出现天数、等级、生命、战斗奖励、沙尘暴状态、物品站位和技能。物品与技能使用实际携带品质的边框和效果。图片生成或发送失败时返回文字。

## 数据与图片

- `monster_data.py` 按 `CombatantType.MonsterTemplateId` 关联战斗遭遇与野怪模板，读取实际物品品质、槽位、附魔、技能及实例属性覆盖。
- 中文沿用 `CardPreviewRepository` 的官方翻译加载方式，优先读取匹配数据库的 `zh-CN.bytes`。
- `monster_sources.json` 保存 Bazaar DB 的公开遭遇列表、出现天数、主图，以及已核对 ArtKey 的虚空骑士卡图来源。资料采集日期会显示在图片中。天数不由等级推算，缺失时明确标注。
- 卡图优先使用现有 `card_images.json`，种子映射仅在 ArtKey 与原始数据匹配时覆盖。小、中、大物品分别使用 CDN 的 `@400S`、`@400`、`@400L` 资源，校验比例为 1:2、1:1、3:2。正方形缩略图不能充当小型或大型原图。
- 图片缓存位于 `plugins/bazaar_plugin/cache/monster_art`，详情图位于 `data/charts/monsters`。图片通过 base64 直接上传，避免经过普通文本回复的 3500 字符截断。
- 缺失历史品质时保留真实品质并标注资料缺失；不改用其他品质。特殊阵容覆盖暂展示基础模板，并给出明确提示。
