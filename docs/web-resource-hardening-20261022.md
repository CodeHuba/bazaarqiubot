# 2026-10-22 故障修复与预防验收说明

2026-10-23 已按用户授权完成生产部署，详见 [上线记录](web-resource-deployment-20261023.md)。以下保留上线前的验收说明及部署预案；监控、资源限制和已确认的旧预览停用现已执行。

## 用户可见行为

- 阵容列表、胜率查询、搭配查询、职业卡牌榜、T 表、阵容榜、阵容分析、职业概况共用最多 2 个重计算名额；后台阵容分析刷新也计入此上限。超出时立即返回 503，提示“查询繁忙，请稍后重试”，附 Retry-After: 3 和 no-store，避免请求无限排队。
- 可用内存低于 384MiB 时不接收新的重查询；执行中低于 192MiB 时，在检查点退出。网站页面和轻量接口继续服务。
- 查询默认执行预算 20 秒。SQLite 通过进度回调中断，主要 Python 数据循环定期检查预算；超时提示用户缩小筛选范围。第三方算法的单次调用只能在调用前后检查，20 秒不是操作系统级强制终止时限。
- 阵容分析冷启动不占着查询名额等待后台刷新，返回可重试的 503；已有缓存时持续提供上一份完整结果。
- 常规查询成功结果和统计口径保持不变，原有搜索记录、功能事件、访问记录继续执行。拒绝和超时按最终 503 状态进入现有统计。

## 降低内存和重复计算

- 旧式卡牌 / 游戏 Day 筛选逐行校验，只保存匹配 ID，再读取当前页；保留总条数、页码校正和原排序。SQL 分页路径继续保留。
- 胜率、搭配、职业卡牌榜、T 表、阵容榜、职业概况逐行消费 SQLite 游标，不将整批原始 JSON 结果驻留在列表中。
- 胜率 Redis 读取每批最多 512 条，Redis 连接及读取具有短超时。
- 阵容榜 FP-Growth 只计算需要的 2 / 3 / 4 项组合，并使用稀疏输入矩阵。
- 相同榜单条件的并发计算合并为一次；榜单结果缓存最多各 64 个条件，写入时清理过期结果。
- 请求创建的 RunsQuery SQLite 连接统一在请求结束时关闭，包括提前返回和异常路径；SQLite 每连接页缓存设置为 2MiB。
- 正常后台分析刷新之间至少间隔 60 秒，采集期间不断变更会合并到下一轮；下一次检测时仍会扫描最新已提交数据，保留已有的更新、删除识别能力。显式 prewarm(wait=True) 用于人工预热，可以绕过间隔。
- 刷新失败只保留异常类型及消息，去除异常调用栈引用，避免失败任务继续引用整批临时数据。

## 监控和服务器保护

新增 `/api/stats/resources`，沿用后台 Basic Auth，仅返回并发数、拒绝 / 中断计数、可用内存及分析缓存状态；响应禁止缓存。

`tools/check_web_resources.py` 是只读探针，记录可用内存、Swap 使用率、内存压力、负载、Caddy / 网站服务状态及公共 HTTPS 状态。输出 JSON 到 journal，并原子更新 `/var/lib/qiubot-health/latest.json`；异常有 severity、连续异常次数和恢复状态。Swap 单独使用率高、但可用内存充足时，不误报当前内存耗尽。探针失败也会显示异常，不返回虚假的健康状态。

`deploy/systemd/qiubot-resource-health.service` 和 `.timer` 是待安装的每分钟监控模板。异常会写告警日志，并让探针服务返回非零状态；没有配置短信、微信或其他外部通知渠道，也不会自行重启服务或清空缓存。

`deploy/systemd/web_runs-resource-limits.conf.example` 是待验证的进程保护候选值：MemoryHigh=2300M、MemoryMax=2800M、MemorySwapMax=256M、TasksMax=128。它不是已启用的线上配置。MemoryMax 超限可能导致进程被终止，必须在生产数据规模的隔离环境观察后才能启用。

应用并发保护按进程计数；当前单进程多线程服务适用。以后若改为多个 WSGI worker，必须重新分配总并发预算。

1. 验收常规查询和上述繁忙 / 超时行为；确认预算不足时提示重试可以接受。

4. 仅发布本轮六个应用文件，先验证查询保护和常规结果，再安装只读健康探针。资源上限需隔离测试验证后单独启用；不能直接照抄候选值。
5. 上线后以少量串行请求检查四个核心搜索入口、冷 / 热查询和后台统计；观察内存、Swap 活动、磁盘等待和 503 占比。保留 Caddy 单独提供 HTTPS 的现状。
6. 如出现结果不一致或持续不可用，恢复本次备份的源码及原 drop-in，再重启网站服务；只移除本次新增的监控 unit，保留故障日志，不清理业务数据或原有统计。
