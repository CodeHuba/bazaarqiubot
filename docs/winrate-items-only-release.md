## 行为

- 只允许物品参与匹配和候选。匹配前依据卡图资料与映射中的 Item/TCardItem 类型过滤技能、事件、野怪及未知类型，不把其他类型标成物品后继续查询。
- 精确物品名、英文名和已配置别名直接查询；非精确输入只有一个物品候选时自动查询，多个候选才提示选择。组合中任一条件未确定时不查询剩余部分，提示保留其他物品和英雄/天数/段位筛选。
- 按卡牌身份而不是索引标签分组，共用 ID 的新旧名称合并；多个真正不同的物品不会仅因中文名相同而合并。
- 同名普通原生物品存在时，排除 `[Community Team]` 内部变体；原有 DEBUG 排除规则保留。判断依据原始身份标签，不按对局数是否为零决定。
- 匹配完成后仅修改请求自己持有的物品索引，避免后续统计再次带入同名技能/事件，不改磁盘映射或共享源数据。
