隐私政策

1. 信息收集

为了提供更好的服务体验和优化产品功能，我们会收集以下信息：

  • 查询记录：您输入的英雄、卡牌、时间范围等查询条件
  • 匿名设备指纹：通过浏览器特征生成的唯一标识符，用于统计独立访客和反馈关联，不包含任何个人身份信息
  • 访问日志：脱敏后的IP地址（仅保留前两段，如 115.238.*.*）、访问时间、页面路径
  • 反馈内容：您主动提交的意见或建议

2. 信息用途

收集的信息仅用于：

  • 提供阵容查询、胜率统计等核心功能
  • 分析用户使用习惯，优化界面和算法
  • 生成匿名的访问统计和热门推荐
  • 回应用户反馈，改进产品质量

我们不会将您的信息用于商业推广、出售给第三方或用于任何未经授权的用途。

3. 数据安全

  • 所有数据存储在安全的服务器环境中，采取必要的技术保护措施
  • IP地址仅保留前两段用于地区统计，不记录完整IP
  • 设备指纹为单向哈希值，无法反向追溯到具体设备
  • 服务器日志定期清理，避免数据过度留存

4. Cookie 使用

本站不使用第三方跟踪 Cookie。仅通过 JavaScript 生成本地设备指纹用于统计，不涉及跨站追踪。

5. 未成年人保护

本服务面向《The Bazaar》游戏玩家，不主动收集未成年人信息。若您未满18周岁，请在监护人指导下使用本服务。

6. 政策更新

我们可能根据法律法规或产品功能变化更新本隐私政策，更新后将在本页面公示。继续使用本服务即视为接受更新后的政策。

7. 联系方式

如对隐私政策有疑问或需要行使数据权利（查询、删除等），请通过以下方式联系：

  • QQ反馈群：bazaarqiubot.com 页面内查看
